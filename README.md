# ZERO / ZERO PiNG

**خدای اپ‌های VPN** — اکوسیستم یکپارچه فروش، مدیریت و اتصال VPN.

> این مخزن فعلاً **فقط معرفی پروژه** است. سورس اپ و Worker هنوز منتشر نشده.

---

## خلاصه

| لایه | نقش |
|------|-----|
| **بات تلگرام** | فروشگاه کامل + نمایندگی + شارژ کیف پول |
| **مینی‌اپ (Telegram WebApp)** | UI شیشه‌ای RTL روی Cloudflare Worker |
| **اپ اندروید ZEROPiNG** | کلاینت VPN واقعی (sing-box / libbox) |
| **پنل‌ها** | تحویل خودکار سرویس از پنل‌های V2Ray / WireGuard |

برند: **ZERO** · **ZERO PiNG**  
رنگ شاخص: طلا `#e4b15a` · پس‌زمینه دارک `#0c0e14`

---

## ۱) بات + مینی‌اپ (Cloudflare Worker)

- فروشگاه محصول / دسته / سبد / سفارش
- کیف پول و شارژ با رسید
- پنل‌های چندگانه
- رفرال (درصد / ثابت / سقف)
- نمایندگی (Agency)
- داشبورد ادمین و مانیتور

**مرجع عملیاتی:** Worker `zero-vpn-v31` · بات `@Gamegozar_app`

API سطح بالا: `/api/shop` · `/api/userinfo` · `/api/topup` · `/api/service` · مسیرهای ادمین

---

## ۲) اپ اندروید — ZEROPiNG

Kotlin + Jetpack Compose · minSdk 26

- ایمپورت اشتراک چندفرمتی و تست تأخیر
- موتور sing-box (libbox) + VpnService
- همگام‌سازی با Worker (شناسه تلگرام / پینگ / ایمپورت کانفیگ سفارش)
